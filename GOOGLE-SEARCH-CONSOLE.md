# Google Search Console setup

Website: [https://mirzazadastudio.com/](https://mirzazadastudio.com/)
Sitemap: [https://mirzazadastudio.com/sitemap.xml](https://mirzazadastudio.com/sitemap.xml)
Robots file: [https://mirzazadastudio.com/robots.txt](https://mirzazadastudio.com/robots.txt)

Status: the sitemap and crawler configuration are live. Account ownership verification and sitemap submission still need to be completed in Google Search Console.

## 1. Get the verification tag

1. Open [Google Search Console](https://search.google.com/search-console/welcome) and sign in to the studio's Google account.
2. Select **URL prefix** and enter exactly **https://mirzazadastudio.com/**.
3. Expand **Other verification methods → HTML tag**.
4. Copy the complete meta tag Google provides and send it to the person maintaining the website.

The tag must be generated by Google for the account being verified. Do not use a sample token. No Google password, OAuth token, or API secret needs to be shared.

## 2. Publish and verify

The maintainer adds Google's exact meta tag inside the head of the repository's index.html file, commits it, and pushes to main. The existing GitHub Actions workflow builds and deploys the website, preserving the tag.

After the deployment succeeds, check the homepage source for the exact google-site-verification tag. Return to Search Console and click **Verify**. Keep the tag in the website after verification, because Google may check it again.

[Google ownership verification documentation](https://support.google.com/webmasters/answer/9008080)

## 3. Submit the sitemap

Open **Sitemaps** in the verified property and submit **sitemap.xml**, or the full URL **https://mirzazadastudio.com/sitemap.xml**.

The sitemap contains public pages and excludes admin routes. After adding projects, changing slugs, or publishing/unpublishing content in the admin, rerun [Deploy Mirzazada Studio](https://github.com/mirzazadastudio-cmd/website/actions/workflows/pages.yml) to refresh the static pages and sitemap.

[Google sitemap submission documentation](https://support.google.com/webmasters/answer/7451001)

## 4. Request initial indexing

Use **URL inspection** for **https://mirzazadastudio.com/**, run **Test live URL**, then choose **Request indexing** if Google reports the page is eligible. Use the sitemap for the remaining pages. Verification and submission do not guarantee indexing or rankings.

[Google URL Inspection documentation](https://support.google.com/webmasters/answer/9012289)

## Optional: verify the whole domain

To cover HTTP, HTTPS, www, and other subdomains with one property, add a **Domain** property named **mirzazadastudio.com**. This method requires the exact Google-provided DNS TXT verification value at Domain.com / Network Solutions. HTML tags cannot verify a Domain property.

Add the TXT record alongside the existing records; preserve the GitHub A records and www CNAME. When the TXT record is visible publicly, return to Search Console and click **Verify**.

[Google property types](https://support.google.com/webmasters/answer/34592)
